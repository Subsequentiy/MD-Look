# MD Look

一个**单文件、纯离线**的 Markdown 阅读器。打开网页即可使用，不需要安装、不上传任何文件。

## 在线使用

部署后访问：`https://<你的用户名>.github.io/<仓库名>/`

## 本地使用

把 `index.html` 下载到本地，双击用浏览器打开即可，功能完全一样。

## 功能

- GFM 完整支持：表格、任务列表、围栏代码块、删除线、自动链接
- 代码块语法高亮 + 一键复制 + 语言标签
- 左侧文件树与大纲，自动高亮当前章节
- 渲染前做 HTML 清洗，`<script>` / `<iframe>` / `on*` / `javascript:` 全部剔除
- 编码自适应：UTF-8（含 BOM）、UTF-16、GBK/GB18030
- 深浅色跟随系统，移动端自适应
- 所有解析都在浏览器本地完成，**文件不会上传到任何服务器**

## 使用方式

| 操作 | 说明 |
| --- | --- |
| 双击空白处 | 弹出文件选择，可多选 |
| 拖放 | 把文件或整个文件夹拖进窗口 |
| `Ctrl + Shift + O` | 打开整个文件夹（相对路径图片、文档间跳转需要这种模式） |
| `/` | 聚焦文件筛选框 |
| `Ctrl + O` | 打开文件 |
| 左侧「文件」右侧的垃圾桶按钮 | 清除全部已加载文件，回到空白状态 |

## 技术

- Markdown 解析：[marked](https://github.com/markedjs/marked) 12.0.2
- 代码高亮：[highlight.js](https://highlightjs.org/) 11.9.0
- 无框架、无构建工具、无 CDN 依赖，所有资源内联在单个 HTML 中
